Above-the-fold shell copy matches the written design specification. Generated
illustrative case names, stationery products, timestamps, values and table columns
were replaced with qualified API data and actual scientific labels. Frozen seed
metadata remains read-only. Existing ranking/history disclosures and provenance
are preserved. Real titles and required metadata make the implementation taller
than the illustrative concept: inspectors continue below the initial viewport.
This intentional data/readability correction avoids dropping diagnostic evidence.

Material fixes: comparison header heights aligned, scenario markers shortened to
avoid awkward wrapping, and mobile active-case positioning moved to a layout
effect to prevent a visible stale scroll position. Core guided-case → resolver →
member inspection → export → replay workflow verified in the browser. Local font
loading, skip navigation and pressed scenario states verified in addition to the
existing interaction suite. No unresolved material layout mismatches remain.

The implementation was faithfully verified against the concept's visual system
and application anatomy, with the scientific-data corrections recorded above.
Firefox/WebKit and participant usability studies remain unqualified.
